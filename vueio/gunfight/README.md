# GHOST POST

A 36-second motion-graphics gunfight short, 1920×1080 at 30 fps with a stereo soundtrack. There are no stock assets: every frame and every sound is generated by code in this folder.

**Logline:** It's 2:13 a.m. in South Central. Deuce finds a hooded stranger standing on his corner. Every bullet passes through the stranger. In bullet time we find out why: the telephone pole behind him is a street memorial dated 1992.

## Files

- `cues.json`: the cue sheet. Every timing (shots, cuts, text, bullet time) lives here. The picture and the audio both read it, so they stay frame-locked.
- `scene.html`: the picture. A Canvas 2D renderer in which every frame is a pure function of time. It covers figure animation (forward kinematics), the parallax street, particles, bullet time and post-processing.
- `audio.py`: the sound design and score, synthesized with NumPy and SciPy. It covers layered gunshots with street slap-back, casings, glass, ricochets, the beat and 808 bass, bullet-time drones, and the title hit.
- `render.cjs`: drives headless Chromium frame by frame and pipes the frames to ffmpeg.
- `build.sh`: runs all of the above and writes `out/ghost-post.mp4`.

## Build

You need Node 22 with Playwright and Chromium, Python 3 with `numpy` and `scipy`, and ffmpeg.

```bash
./build.sh
```

This builds the 1080p master, `out/ghost-post.mp4` (H.264). Rendering is CPU-only and takes a few minutes.

### 8K

```bash
./build-8k.sh
```

This builds `out/ghost-post-8k.mp4`: native 7680×4320 at 30 fps, 10-bit HEVC (Main 10) with 320 kbps AAC audio, about 440 MB. The renderer draws in 1920×1080 logical coordinates at any output scale, so every 8K frame is redrawn, not upscaled. The build has two stages:

1. Three browser workers draw JPEG frames to `out/frames8k/` (about 4 GB of temporary files). This stage is resumable: re-running skips frames already drawn.
2. One HEVC encode. It needs about 6 GB of RAM, so it runs on its own, after drawing.

On a 4-core machine with no GPU, drawing takes about 25 minutes and encoding about 30. The 8K file is larger than GitHub's 100 MB per-file limit, so it isn't committed.

The audio is limited at 4× oversampling, so peaks stay under -1 dBTP after AAC encoding. Loudness is -16 LUFS.

To render single frames for checking:

```bash
node render.cjs --stills 12.5,21.0,30.2 /tmp/stills
```

To change the edit, adjust times in `cues.json`. The picture and the sound both follow.

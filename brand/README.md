# Ghost Post brand kit

The mark is a pulse line that ends in a node with two branches: content going out to the apps you connect.

| File | Use |
|---|---|
| `ghost-post-icon.svg` / `ghost-post-icon-1024.png` | App icon with rounded corners (web, social avatars) |
| `app-store-icon-1024.png` | Apple App Store icon: square, no transparency (Apple applies the corner mask) |
| `play-store-icon-512.png` | Google Play icon: square, no transparency |
| `ghost-post-icon-square.svg` | Full-bleed source for store icons |
| `ghost-post-mark-dark.svg`, `ghost-post-mark-light.svg` | Mark only, for use on your own backgrounds |
| `ghost-post-lockup-*.svg/png` | Icon plus the "Ghost Post" wordmark (outlined from Poppins Bold, so no font install is needed) |

Colours: mint `#8CF9CB` → `#1CD28B`, ink `#07080B`. Poppins Bold is licensed under the SIL Open Font License (`assets/fonts/LICENSE.txt`).

These are proposals. The app currently ships `public/icons/*` (a similar pulse mark). To switch, regenerate those PNGs from `ghost-post-icon.svg` and the maskable version from `ghost-post-icon-square.svg`, and replace `mobile/assets/icon.png`. Nothing was replaced automatically.

Check that the mark isn't confusingly similar to another product's logo in the app stores before you trademark it.
